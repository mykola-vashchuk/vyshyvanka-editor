# Vyshyvanka Editor

JavaFX-редактор схем української вишивки з малюванням по сітці, вибором кольору та типу стібка, симетрією, зміною розміру, дублюванням фрагмента, масштабуванням/панорамою та збереженням/імпортом PNG.
