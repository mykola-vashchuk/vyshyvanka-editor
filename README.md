# Vyshyvanka Editor

JavaFX-редактор схем української вишивки з малюванням по сітці, вибором кольору та типу стібка, симетрією, зміною розміру, дублюванням фрагмента, масштабуванням/панорамою та збереженням/імпортом PNG.

Автор: Микола Ващук | НаУКМА - 2026
## Можливості

- малювання по клітинках на полотні;
- вибір кольору нитки;
- вибір типу стібка (CROSS_STITCH / FILLED_SQUARE);
- симетрія (горизонтальна/вертикальна);
- зміна розміру сітки;
- дублювання фрагмента орнаменту;
- масштабування та панорама полотна;
- приховування/показ панелі інструментів;
- збереження та імпорт PNG.
